            수집하는 정보

            Google 계정 식별자와 이메일, 이름 또는 닉네임, 나이, 선택 프로필, 프로필 사진, 클럽 역할, 일정 응답, 출석과 관리 작업 기록을 처리합니다. 푸시 알림을 켜면 브라우저 구독 주소, 기기별 암호화 키와 선택한 알림 종류를 추가로 처리합니다.

            이용 목적과 공개 범위

            회원 확인, 비공개 클럽 운영, 일정·참가·출석·공지 관리에 사용합니다. 이메일은 다른 회원에게 공개하지 않으며 공개 프로필과 활동 현황은 같은 클럽의 활성 회원에게만 표시합니다.

            외부 서비스

            Google은 로그인을, Supabase는 인증·데이터베이스·파일 저장을, GitHub Pages는 공개 정적 화면 배포를 담당합니다. 서비스 역할 키와 OAuth 비밀값은 브라우저에 저장하지 않습니다.

            보관과 삭제

            회원 데이터는 계정과 클럽 운영 중 보관합니다. 알림 구독은 본인이 끄거나 클럽 활동이 중단되면 비활성화합니다. 삭제 요청 시 클럽 접근을 즉시 중단하고 감사 기록의 회원 이름과 식별자를 익명화합니다. 운영자는 프로필 사진을 Storage API로 제거한 뒤 Supabase Auth 계정을 최종 삭제합니다.

            계정 삭제 요청

            내 정보 → 계정 삭제 요청을 사용합니다. 총관리자는 클럽 소유권을 먼저 정리해야 합니다. 요청 후 복구가 필요하면 Auth 계정이 최종 삭제되기 전에 클럽 운영자에게 문의해야 합니다.
