# 웹 MVP 개발 계획

한 번에 한 단계만 구현하고, 각 단계가 검증되면 버전 커밋·태그·푸시한다.

## 단계 0. 방향 전환과 사양 정리 — `v0.1.0`

- Flutter/Firebase 프로토타입 보존
- HTML, CSS, JavaScript와 GitHub Pages 확정
- Supabase 책임과 보안 경계 확정
- 반응형 기본 화면과 자동 배포 구성

완료 조건: 정적 테스트 통과, 데스크톱·모바일 화면 확인, Pages 배포 성공.

## 단계 1. Supabase 개발 환경과 Google 로그인 — `v0.2.0`

- 개발용 Supabase 프로젝트
- profiles 테이블과 RLS
- Google OAuth
- 로그인 유지와 로그아웃
- 인증 전후 hash route 보호

완료 조건: GitHub Pages에서 실제 Google 로그인과 본인 프로필 조회 성공.

## 단계 2. 프로필 — `v0.3.0`

- 최초 작성과 수정
- 프로필 사진 압축 및 Storage 업로드
- 사진 크기·MIME·소유권 정책
- 기본 프로필 이미지

## 단계 3. 클럽과 초대 코드 — `v0.4.0`

- 클럽 생성
- 해시된 고정 초대 코드
- 코드 가입 함수
- 초기 한 클럽 제한
- 회원 공개 프로필

## 단계 4. 권한과 회원 관리 — `v0.5.0`

- owner, admin, member
- 관리자 지정·해제
- 회원 목록과 강제 탈퇴
- 감사 로그

## 단계 5. 일정 — `v0.6.0`

- 이벤트 작성·공개·수정·취소
- 일정 목록과 상세
- 정원과 신청·취소 마감 검증

## 단계 6. 참가·대기·취소 — `v0.7.0`

- 원자적 참가 신청
- 대기 순서
- 불참과 취소
- 자동 승급
- 동시 마지막 자리 테스트

## 단계 7. 출석과 통계 — `v0.8.0`

- 관리자 출석 체크
- 공개 출석 결과
- 월별 참석 집계

## 단계 8. 공지와 운영 안정화 — `v0.9.0`

- 공지 작성·수정·고정
- 오류와 빈 상태
- 접근성, 시간대, 네트워크 재시도
- 데이터 백업 절차

## 단계 9. 첫 운영 릴리스 — `v1.0.0`

- 실제 회원 시범 운영
- 권한·동시성 통합 테스트
- 개인정보 처리와 계정 삭제 절차
- 사용량 확인

Kakao 로그인과 PWA 설치 지원은 첫 운영 릴리스 이후 별도 단계에서 판단한다.
