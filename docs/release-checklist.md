# v1.0.0 첫 운영 릴리스 체크리스트

이 체크리스트는 실제 회원 초대 전에 한 번, 이후 주요 버전마다 반복한다. 테스트 데이터와 계정은 운영 데이터와 구분한다.

## 1. 배포와 인증

- [ ] GitHub Actions 테스트와 Pages 배포 성공
- [ ] 공개 사이트의 버전이 Git 태그와 일치
- [ ] Google 로그인, 로그인 유지와 로그아웃 성공
- [ ] 로그인 전 보호 화면 접근 시 로그인 화면으로 이동
- [ ] 로그인 전 개인정보 처리 안내 접근 가능

## 2. 역할과 회원

- [ ] owner만 관리자 지정·해제, 회원 탈퇴와 감사 기록 조회 가능
- [ ] admin은 일정·참가자·출석·공지 관리 가능
- [ ] member는 관리 버튼이 없고 서버 함수 호출도 거부됨
- [ ] 초대 코드 재발급 후 이전 코드 무효화
- [ ] 탈퇴 회원이 새 초대 코드로 정상 재가입 가능

## 3. 일정과 동시성

- [ ] 일정 임시 저장·수정·공개·취소 성공
- [ ] 신청과 취소 마감이 데이터베이스 시각으로 거부됨
- [ ] 정원 마지막 한 자리에 두 계정이 거의 동시에 신청해 한 명만 확정
- [ ] 나머지 한 명은 대기 1순위
- [ ] 확정 취소 시 대기 1순위 자동 승급
- [ ] owner/admin 변경과 회원 직접 응답 후 공식 카운트 일치

## 4. 출석과 공지

- [ ] 시작 전 출석 저장 거부, 시작 후 owner/admin 저장 성공
- [ ] member는 출석 결과와 월별 통계만 조회
- [ ] 미체크 해제와 감사 기록 성공
- [ ] 공개 기간 안의 공지만 member에게 표시
- [ ] 임시·예약·종료·보관 공지는 member에게 비공개
- [ ] 중요 공지 고정, 수정, 보관과 감사 기록 성공

## 5. 개인정보와 계정 삭제

- [ ] owner의 계정 삭제 요청 거부
- [ ] 테스트 member의 삭제 요청 후 즉시 로그아웃 및 클럽 접근 중단
- [ ] 요청 회원의 미래 참가 취소와 대기 자동 승급 확인
- [ ] 감사 기록의 이름과 ID가 `탈퇴 회원`으로 익명화
- [ ] Storage 프로필 사진 삭제 후 Auth 사용자 최종 삭제
- [ ] Auth 삭제 뒤 프로필·회원·요청 행 제거 및 작성자 참조 `null` 확인
- [ ] 삭제 요청 계정의 클럽 재가입 거부

## 6. 화면과 복구

- [ ] 320px 모바일, 태블릿과 데스크톱 레이아웃 확인
- [ ] 키보드만으로 내비게이션, 폼, 버튼 사용 가능
- [ ] 포커스 표시와 오류 안내 확인
- [ ] 일정·출석·공지 조회 실패 후 **다시 시도** 동작
- [ ] 로딩, 빈 상태, 권한 부족 상태 확인

## 7. 운영 준비

- [ ] 마이그레이션 직전 데이터베이스와 Storage 백업
- [ ] 백업 파일 크기와 해시 확인, Git 미추적 확인
- [ ] Supabase Usage에서 Database, Storage, Egress와 MAU 기록
- [ ] GitHub Actions 사용량과 최근 실패 확인
- [ ] owner 한 명과 승인된 admin 목록 확인
- [ ] 운영자 연락 방법을 개인정보 처리 안내에 추가할지 결정
